# StockSense-AI: Serialized ML Models Directory

This directory stores serialized model artifacts and preprocessing scalers generated by `ml/train.py`:

- `xgboost_model.pkl` ⭐: Champion Gradient Boosted Tree Classifier for tomorrow's UP/DOWN direction.
- `random_forest_model.pkl`: Model 2 Bagging Ensemble Classifier (150 decision trees).
- `logistic_regression_model.pkl`: Model 1 L2-Regularized Linear Baseline.
- `price_regressor_model.pkl`: Price approximation regressor (tomorrow's expected price).
- `scaler.pkl`: StandardScaler fitted strictly on TRAIN (2018-2023) to eliminate data leakage.
- `model_metadata.json`: Timestamp, feature configuration, validation scores, and target specifications.

To train and generate or refresh the `.pkl` artifacts, run:
```bash
python -m ml.train
```
